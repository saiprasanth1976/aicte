ROLE

VISUAL DIRECTION

Use photorealistic live-action visuals.

- Cool monitor lighting balanced with realistic ambient office lighting.
- Natural human expressions before exaggerated comedic reactions.
- Controlled dolly movements and slow push-ins.
- Deliberate rack focus.
- Smooth, motivated transitions.
- Consistent character appearance, clothing, and environment across related shots.
